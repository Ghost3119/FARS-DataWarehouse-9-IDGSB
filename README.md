## Caso de uso

Una dirección de seguridad vial quiere identificar combinaciones de horario, ubicación y condiciones de circulación asociadas con mayor cantidad de siniestros mortales.

## Alcance

Conservar los archivos originales publicados por NHTSA para 1975–2024, los auxiliares y la documentación del directorio FARS. La limpieza corresponde al equipo y todavía no se ha realizado. No se ha elegido un motor ni implementado una base de datos.

Fuente: https://www.nhtsa.gov/file-downloads?p=nhtsa/downloads/FARS/
